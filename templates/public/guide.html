DOCUMENTATION / USER GUIDE

Use the tracker
without extra ceremony.

A concise reference for registration, sessions, Markdown reviews, privacy, and account access.

01ACCOUNT ACCESS

Register with an invite

Choose password signup or Passkey-only signup. Both require a valid invite unless an administrator has explicitly opened registration. A Passkey-only account stores no password. Registration errors appear above the form.

02START / FINISH

Record one focused session

Start a subject from the homepage. Running duration stays hidden. When finished, provide one title and a Markdown details body. Sessions shorter than 25 minutes or longer than 12 hours are discarded.

03MARKDOWN

Keep formulas and structure

Details support KaTeX formulas with Classic, Minimal, Paper, and Blueprint styles, plus GFM tables, task lists, code highlighting, footnotes, callouts, marks, superscript, and subscript. Input preview is optional and disabled by default.

04REVIEW

Read before editing

Historical sessions open in Markdown preview. Full-screen reading keeps its exit control visible and supports vertical touch scrolling. Use Edit only when changes are needed. The eye indicator and chart show review activity per session.

05ACTIVITY

Inspect a day

Select a heatmap cell to view that day's online and offline timeline. Select a session title to open its review. The five-hour threshold uses a high-contrast heatmap color.

06DATA ISOLATION

Accounts remain separate

Every user sees only their own sessions and exports. Only the instance superuser synchronizes private `.env` display settings; ordinary users never receive the study-room code or private homepage content.

07MATH LAB

Open mathematics on demand

Enter Math Lab from the app sidebar or the immersive reader. Explore linear and complex mappings, Fourier/FFT, Laplace integration, and orbitable 3D surfaces. Renderers stay unloaded until selected and fall back to Canvas when GPU features are unavailable.

IOS SHORTCUTS / 快捷指令

Unauthenticated start and disturbance automation

Each capability uses two different secret URIs: one may only start its assigned subject, while the other may only record a disturbance against the currently running session.

ENGLISH

A. Create the capability

  1. Sign in and open Settings → Start and disturbance URIs.
  2. Select the subject and validity window. The default window is 06:00–22:00 Asia/Shanghai.
  3. Select Create capability. Save both secret URIs before closing the dialog; the server stores hashes and cannot display the raw values later.

B. Build the Start Study shortcut

  1. Select Copy & Open Shortcuts beside Shortcut Start · POST. iOS opens a new empty shortcut and the URI is already on the clipboard.
  2. Add the Get Contents of URL action, paste the URI, change Method to POST, and leave Headers and Request Body empty.
  3. Name it, for example “Start Mathematics”. Run it once to verify the JSON response says started or existing.
  4. Optionally add it to the Home Screen, Lock Screen, widget, Action Button, NFC, Focus, or another personal automation.

C. Record charger-disconnection disturbances

  1. Copy the separate Disturbance · POST URI.
  2. In Shortcuts open Automation → + → Charger → Is Disconnected. Choose Run Immediately.
  3. Add Get Contents of URL, paste the disturbance URI, choose POST, leave the body empty, and save.
  4. Each trigger increments the current Session disturbance count once. If no Session is running, the request is a no-op. A stale Session over 12 hours is discarded.

D. Pause, schedule, and rotate

Pause temporarily disables both URIs without changing either Shortcut. Resume restores them. Configure changes the daily window; equal start/end means all day, and an overnight range such as 22:00–06:00 is supported. Outside the window, a valid URI returns a successful no-op. Generate a new URI if a secret was lost or exposed; the previous URI becomes invalid immediately.

中文

A. 创建能力链接

  1. 登录后打开设置 → Start and disturbance URIs。
  2. 选择科目和每日有效时段；默认使用上海时区 06:00–22:00。
  3. 点击 Create capability。关闭弹窗前保存两个秘密 URI；服务器只保存哈希，之后无法再次显示原始 URI。

B. 创建“开始学习”快捷指令

  1. 点击 Shortcut Start · POST 旁边的复制并打开快捷指令。iOS 会打开一个空白快捷指令，URI 已在剪贴板中。
  2. 添加获取 URL 内容动作，粘贴 URI，把方法改为 POST；请求头与请求正文均留空。
  3. 命名，例如“开始数学”。先运行一次；JSON 返回 started 或 existing 即为正常。
  4. 随后可以添加到主屏幕、锁屏、小组件、操作按钮、NFC、专注模式或其他个人自动化。

C. 记录断开充电器造成的扰动

  1. 复制单独的 Disturbance · POST URI。
  2. 在快捷指令中打开自动化 → + → 充电器 → 已断开连接，选择立即运行。
  3. 添加获取 URL 内容，粘贴扰动 URI，方法选择 POST，正文留空并保存。
  4. 每次触发只给当前运行中的 Session 增加一次扰动；没有运行任务时为空操作。超过 12 小时的遗留任务会被直接丢弃。

D. 暂停、时段与换新

Pause 会临时关闭两个 URI，但不改变快捷指令里的地址；Resume 后恢复。Configure 可修改每天的有效时段；开始和结束相同表示全天，22:00–06:00 这样的跨夜时段也支持。时段外请求会成功返回但不执行任何写入。URI 泄露或丢失时生成新 URI，旧 URI 会立即失效。

Security / 安全： The URI itself is the credential. Do not publish it, include it in screenshots, or send it through untrusted analytics. Use HTTPS and keep access logging disabled for these paths. URI 本身就是凭据，请勿公开、截图传播或交给不可信分析服务；务必使用 HTTPS，并关闭这些路径的访问日志。
INVITE SHARING

One daily invite for every member

Ordinary users can generate one single-use invite per Shanghai calendar day from Settings. After redemption, the issuer can see the registered username. Administrators retain configurable 1–100-use invitations.

ACCESS RECOVERY

Twenty failed attempts

The twenty-first failed password attempt within fifteen minutes temporarily limits that network. Administrators can inspect and reset login status from Django Admin. Enrolled Passkeys remain the recommended sign-in method.

PORTABILITY

Export before you need it

Availability and zero data loss are not guaranteed. Download complete CSV, JSON, or Markdown records from Settings. Read the bilingual disclaimer.

SUPPORT

Registration or access issue?

Contact the administrator directly. Messages submitted through this site are sent by email and are not stored in the tracker database.
