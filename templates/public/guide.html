DOCUMENTATION / USER GUIDE

Use the tracker
without extra ceremony.

A concise reference for registration, sessions, Markdown reviews, privacy, and account access.

SIGN INREGISTER WITH INVITE
01ACCOUNT ACCESS

Register with an invite

Open the registration page and enter a username, password, and administrator-issued invite code. One invite can be configured for multiple uses. Passkeys can be added later from Settings.

02START / FINISH

Record one focused session

Start a subject from the homepage. Running duration stays hidden. When finished, provide one title and a Markdown details body. Sessions shorter than 25 minutes or longer than 12 hours are discarded.

03MARKDOWN

Keep formulas and structure

Details support KaTeX formulas, GFM tables, task lists, code highlighting, footnotes, callouts, marks, superscript, and subscript. Input preview is optional and disabled by default.

04REVIEW

Read before editing

Historical sessions open in Markdown preview. Use the full-screen button for reading and the separate Edit button only when changes are needed. The eye indicator and chart show review activity per session.

05ACTIVITY

Inspect a day

Select a heatmap cell to view that day's online and offline timeline. Select a session title to open its review. The five-hour threshold uses a high-contrast heatmap color.

06DATA ISOLATION

Accounts remain separate

Every user sees only their own sessions and exports. Administrator Markdown is archived on the main GitHub branch; invited users use username-derived branches.

SUPPORT

Registration or access issue?

Contact the administrator directly. Messages submitted through this site are sent by email and are not stored in the tracker database.
