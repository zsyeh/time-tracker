## 本次吸取的经验

1. 按范围备份真实有效：2秒/959KiB替代此前2.87GB全库；开发没有等待备份。
2. 针对性gate44秒替代反复全量PG；保留已通过结果，结构变更只修对应断言。
3. 仍有浪费：宽屏诊断的父子容器规则在首发后才复核，导致一次补发；下次在首发前直接看一个展开状态截图，避免只验收默认折叠状态。
4. 本地浏览器初次未指定已安装Chrome路径、线上首次探针表达式遇到CSP、另一次探针与重启重叠，都属于验证脚本问题；以后复用已知环境和箭头函数，并严格等healthy后开始冒烟。**开发可和备份并行，服务切换与线上验收不能并行。**
5. 打包/构建完成到执行切换仍有几十秒协调空档；下一次用固定串行发布脚本接健康探针，减少Agent反复查看日志的空隙。
6. 不为追求绝对零等待预下载5000张图；真正改善是取消无用中途任务、优先最终视口，保留内存边界与可回滚发布。
