# EI 信号严选 v1

入口 `/signal-selected`，接口 `/api/drill/signal-selected/`。复用电路严选的安全筛选和虚拟集合逻辑，但信号使用独立清单、规则和入口。仅 EI workspace 可访问；无 migration、无数据库导入、不复制题图或学习记录。

## 范围和优先级

采用用户提供的 892 复习优先级，参考项目现有 `drill.ei_syllabus.SYLLABUS['signals']`。这不是命题概率统计，也没有把 859 专业卷深度等同于 892。运行时不调用模型，不创建 embeddings。

盘点 VPS 文档 14、23、26 共 974 条现有记录：选入 317，待复核 419，不纳入 238。选入来源分别为基础书 37、课后题 102、859 真题 178。旧版课后题与新版配对书中同号条目优先采用新版，旧题、答案、进度不删除也不合并。整卷容器不与子题重复计数。

| Z 变换 / 差分方程 | 65 |

训练层次：核心 174、进阶 13、基础 130。选择、填空、判断和简答不冒充计算大题；17 道含 Z/差分方程初始条件标签，可与“计算／综合”筛选组合使用。默认核心且本题题答已具备；用户可查看所有匹配或按掌握状态筛选。

“拉氏／系统响应”包含求响应的时域基本练习，并非每题都指定拉氏法。Z 类同样包含差分方程基础解法；不要从分类名称推断原题强制要求某种变换。

## 可重复筛选

`drill/signal_selection_rules.py` 定义九类关键词、优先级、概念题降层和非主攻扩展项。只用题干证据归类，不借邻题答案判断本题。冲激抽样性质不当成抽样定理，佩利–维纳不当成维纳–辛钦，DFT/FFT、同态滤波、复杂全通/状态空间等留复核。题意不足不只凭章节号猜测。

证据来源：可靠结构化题文；新版课后题原 PDF 的现有 bbox 内文字层；已有真题 OCR/题号缓存。没有新增全书 OCR、没有模型逐页读 PDF，也没有重新裁图。真题按现有下一题 anchor 截断文字证据，并剔除尾部下一节标题。现有裁图是否完美不由关键词算法认证；“题答已具备”仅表示素材存在且无未处理勘误。

生成器只输出 JSON，不连接数据库：

```sh
python3 scripts/build_signal_selected.py \
  --inventory /private/inventory.json \
  --workbook-text /private/workbook-text.json \
  --index /private/index.json \
  --cache /private/ocr-cache --output selected
```

另支持 `--output review` / `stats` 和重复 `--cache`。提交的清单是 `drill/data/signal_selected_v1.json` 与 `signal_selected_review_v1.json`，保留 UUID、fingerprint、规则结果和短证据。原始全文导出和 OCR 缓存保持私有，不随仓库提交。

## 进度和发布

复用当前登录用户原题的 QuestionAttempt；组头和总表头展示已做、未做、master 及两种 master 率。下一题/顺序题/待复习/到期复习都限制在当前信号集合筛选内；不会跳到电路组。返回保留筛选并定位当前题。原卷和完整版答案入口保持不变，原书部分超纲及题答资料不足明确标识。

发布顺序为 GitHub 提交 → VPS fast-forward → 合并前端构建 → collectstatic → Gunicorn HUP。保留旧哈希静态资源，数据库不覆盖，本地镜像同步代码但不从本地向 VPS 灌库。

验证包含规则误判回归、同一套集合安全/用户隔离契约、信号/电路导航隔离及前端参数测试；浏览器临时会话拦截学习记录写入，在 1440/390 宽度检查九组、317 个唯一原题、状态一致、题答加载、筛选跳转和返回定位。
