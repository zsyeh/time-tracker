# EI 电路严选 v1

入口：`/circuit-selected`；接口：`/api/drill/circuit-selected/`，仅 EI workspace。

这是按用户的 892 复习优先级建立的虚拟专题集合，不是命题概率预测，也不是新的考纲认证。复用原题 UUID、题图、答案、勘误、QuestionAttempt 和掌握状态；不复制题目，不导入生产数据，不增加迁移或图片存储。

## 使用与限制

- 默认“核心必练 + 题答已具备”；可查看全部 211 道，按考点、层次、概念/计算、资料、掌握状态和综合题过滤。
- “题答已具备”只表示存在本题题图/题文及答案且无未处理勘误，不代表所有裁图都经过视觉质量认证。
- 原页定位、整卷答案待核对、原真题书部分超纲均明确标注。原卷和完整版答案入口保留。
- 热力图及已做/未做/掌握率使用当前登录用户的原记录；不会创建独立进度副本。
- 下一题、顺序下一题、待复习和到期复习均限制在当前集合筛选内；返回保留筛选并定位原题。
- UUID/fingerprint 不匹配或已标记超纲的题目不进入实际结果；实际可见数可能随生产勘误/资料/考纲状态改变。

## 验证与发布

新增七项后端测试、两项前端过滤参数测试。Django drill 全部 149 项及相关 drill_sources/严选/原卷定向测试通过；前端既有 12 项与新增 2 项测试通过，Vue TypeScript / Vite 构建通过。浏览器使用临时会话并拦截学习记录写入，覆盖桌面/手机、11 组、原题进度、题答加载、筛选内跳转和返回定位。

先推送 GitHub，再在 VPS fast-forward 拉取；只发布代码和前端构建，collectstatic 后 HUP Gunicorn。不覆盖数据库、不重建题图、不删除已有资源或远端未跟踪文件。前端旧哈希资源保留以兼容打开中的页面。
