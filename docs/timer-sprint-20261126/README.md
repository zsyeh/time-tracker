# Timer：考研最后20天冲刺

## 需求及口径

- 每日基础681分钟（11小时21分钟），20天共13620分钟（227小时）。账号偏好 `timer.goal_plan` 保存模式及起始日期；原模式仍可选，不改其他账号默认。
- 数学二300分钟，Selected严选30题；892专业课240分钟，20–30题、旧知识复测及新考点；英语二111分钟，完形15、阅读四篇各19、新题型10、翻译10；政治30分钟。题量是任务目标文案，不修改题库统计或自动生成作答。
- 默认启用日2026-11-26，到2026-12-15（含首尾）。页面可调整日期，服务端校验合法日期并跨设备同步。
- 基础净时长不乘效率系数。作文及明确名为“错题订正”的任务、或带“冲刺额外任务”标签的任务，计入实际学习但不抵扣基础目标；普通复测/复习不误归为额外。
- 每科实际时间可超过目标，百分比可超过100%；条形图封顶100%。今日目标记入时长是各科 `min(基础净时长,该科目标)` 之和。20天累计按逐日、逐科封顶后相加，超额不转移。
- 完成及进行中任务都计入实时目标。自然日按Asia/Shanghai切分，跨午夜暂停区间也按日正确扣除。休息须点击“暂停休息”，系统不能推断用户离开；继续学习不创建新记录。
- 冲刺模式保留不足25分钟和超过12小时的任务；不自动截止。原模式保留既有规则。
- 原有历史热力图、效率等级及历史加权统计不重新计算；新增冲刺面板与“今日各科”在冲刺模式显示实际净时长。任务、学习记录及题库均不删除、不回填伪造记录。

## 数据与迁移

唯一迁移为tracker0023：`TimeLog.pause_intervals` JSON，默认`[]`。只增加列，不修改旧记录的开始/结束时间、题库状态、分数或统计定义。暂停API必须登录，查当前账号且status为running的记录；重复暂停不会重复追加区间。

启用命令：

```sh
python manage.py configure_sprint20 --username eh --start-date 2026-11-26
```

先用ORM解密后比较已有任务名，再创建缺少的预设，避免加密字段直接SQL按明文查询导致重复。用户行锁及事务保护配置和预设；重复执行创建数应为0。英语7个子任务用于按既定顺序启动，作文与四科错题订正带额外标签；不强制把英语分项作为独立不可互补目标。
