## 结果解释与未通过的性能目标

- 搜索点击由约7.1秒降至206ms；首张真实题图由约7.3秒降至950ms。原点击有两个相同目标详情 GET，after 为一次。
- 首次题目 UI 中位基本相当，真实题图中位改善；下一题 UI 改善，但图片网络完成的中位变慢（70→363ms）。不得将所有题图加载均标为改善。
- 本次生产冷启动严选热力图首屏中位由1304升至1950ms，尚未达到生产首屏恢复或改善目标。API响应头中位约123→160ms，完整响应中位约611→617ms，传输大小均307638字节、963格；新增冷启动等待不能未经进一步分段直接归因数据库。局部渲染基准改善不能替代这项线上结果。
- before首次题目及next存在约2.2–2.8秒尾部，after热力图存在3278ms尾部；原始样本完整保留。
- 仅3次样本，用中位及原始值描述。JSON中的nearest-rank P95等于最大值，不是稳定的生产P95估计，应结合较大样本API基准。

## 图片传输、缓存和主线程口径

- JSON按动作记录 Chrome CDP 图片状态码、网络编码传输字节、disk/memory/prefetch/service-worker缓存计数。字节包含该动作开始的相邻题与答案预加载，不是单张题图payload大小。
- next/previous命中动作开始前已发起的预取时，动作图片新请求可为0；这不表示题图文件为0字节。
- 每次冷context图片成功记录HTTP200；未强制清缓存或关闭预取。部分相邻图在动作结束时尚未完成，保留null状态/未完成计数，不伪造传输数据。
- Chrome支持Long Tasks观测。首开主线程长任务总和before中位456ms、after451ms；搜索点击154→152ms；严选热力图398→423ms；next/previous均无>50ms任务被捕获。网络等待与长任务分开记录。

独立脚本和身份文件只保存在主机私有目录；本目录JSON不含会话cookie、UUID、题目正文、资源URL或用户身份。
